# 솔커트캐릭터 스킬

솔커트 스틱 파우치 의인화 캐릭터 레퍼런스(기준 이미지·누끼·배경·합성 스크립트). 클로드 코드에서 "솔커트 캐릭터" 또는 `/솔커트캐릭터`로 불러온다.

## 설치
```
cd ~/.claude/skills        # 윈도우: cd C:\Users\<사용자>\.claude\skills
git clone https://github.com/Titanomics/solcut-character-skill.git 솔커트캐릭터
```
클로드 코드 재시작. 배경 합성(`compose.py`)은 `pip install pillow` 필요.

## 업데이트 받기
```
cd ~/.claude/skills/솔커트캐릭터
git pull
```
